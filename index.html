إعدادات المشغّل

مفعّلة افتراضياً. عند إلغائها تظهر أزرار يوتيوب الأصلية ويمكنك لمس النافذة مباشرة. الإعداد يُحفظ في متصفحك أنت فقط.

الاتصال بـ GitHub

اربط الموقع بمستودعك على GitHub ليتم حفظ إضافاتك مباشرة في ملف data/videos.json داخل المستودع. أي شخص يفتح الرابط بعد الاستضافة سيرى نفس المكتبة فوراً، دون الحاجة لإعادة نشر الموقع.

لإنشاء رمز وصول آمن: من GitHub اذهب إلى Settings → Developer settings → Fine-grained tokens، اختر هذا المستودع فقط، وامنحه صلاحية Contents: Read and write فقط. لا تُدرج الرمز أبداً داخل ملفات المستودع نفسها.
بدون رمز، سيعرض الموقع المكتبة للقراءة فقط (للزوار). أدخل الرمز في متصفحك أنت فقط لتفعيل التعديل.
